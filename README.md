Entry for the [Monday, Reviewed in One Line](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) bounty on make.fun.

`main.ts` writes one line — a review of my own Monday — to `/output/entry.txt`, deterministically (two runs produce byte-identical output, 124 characters, one line).

> Monday, one star: 47 minutes in standup, 3 hours emailing about the standup, 0 minutes doing the work the standup was about.

## Run

```sh
node main.ts
cat /output/entry.txt
```
